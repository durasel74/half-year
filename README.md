# Открытка «С Полугодовщиной» — локальная версия

Полностью автономный сайт на чистых **HTML + CSS + JavaScript**: без Node.js,
без сборки и без интернета (шрифты лежат в папке `fonts/`).

## Как открыть

**Способ 1 — просто открыть в браузере.**
Дважды кликните `index.html` — открытка заработает сразу.

**Способ 2 — через VS Code (рекомендуется).**
1. Откройте папку проекта в VS Code (File → Open Folder…).
2. Установите расширение **Live Server** ( Ritwick Dey, Live Server ).
3. Кликните правой кнопкой по `index.html` → **Open with Live Server** —
   страница откроется с автоперезагрузкой при сохранении файлов.

## Структура папок

```
greeting-card-local/
├── index.html          — разметка открытки (каркас: фон, письмо, панель тем)
├── css/
│   ├── theme.css       — ВСЕ ЦВЕТА открытки в одном месте (палитра --pal-*)
│   ├── card.css        — все стили и анимации (фон, ленты, письмо, панель)
│   ├── base.css        — мини-сброс базовых стилей браузера
│   └── fonts.css       — подключение локальных шрифтов (@font-face)
├── js/
│   ├── content.js      — ТЕКСТЫ ПИСЬМА и тайминги (задержки, паузы)
│   ├── compliments.js  — СЛОВА-КОМПЛИМЕНТЫ для ленточек
│   ├── palettes.js     — цветовые темы (6 штук) + настройки «Ночи»
│   └── main.js         — логика: частицы фона, ленточки, письмо, панель тем
└── fonts/              — шрифты Caveat и Cormorant Garamond (кириллица, woff2)
```

## Что и где редактировать

| Что хотите поменять                      | Файл                                    |
| ---------------------------------------- | --------------------------------------- |
| Текст письма, заголовок, подпись          | `js/content.js` (массив `paragraphs`)   |
| Слова-комплименты на ленточках            | `js/compliments.js`                     |
| Задержку письма, паузы между ленточками   | `js/content.js` (тайминги, в мс)        |
| Палитру открытки                          | `css/theme.css` (шесть `--pal-*`)       |
| Набор тем и их цвета                      | `js/palettes.js` (массив `PALETTES`)    |
| Скорость/стиль анимаций                   | `css/card.css`                          |
